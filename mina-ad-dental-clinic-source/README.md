# د. مينا عادل لطب وتجميل الأسنان

موقع عربي RTL احترافي ومتجاوب لعيادة د. مينا عادل لطب وتجميل الأسنان، مبني بواجهة React + TypeScript + Vite + Tailwind CSS.

## الموجود داخل المشروع

- صفحة رئيسية عربية RTL مع Hero، الخدمات، لماذا نحن، رحلة المريض، مقارنة قبل/بعد تجريبية، الفروع، الأسئلة الشائعة، والحجز.
- صفحة مستقلة للخدمات على المسار `/services`.
- نموذج حجز تفاعلي يعرض رسالة نجاح محلية، مع توضيح أن الطلب لا يصبح موعدًا مؤكدًا إلا بعد تواصل العيادة.
- زر اتصال مباشر بالرقم `01111447874`.
- أزرار WhatsApp برسالة جاهزة إلى الرقم `201111447874`.
- شريط إجراءات ثابت للموبايل: اتصال، WhatsApp، احجز الآن.
- SEO: عنوان ووصف، Open Graph، Schema Markup من نوع Dentist، `robots.txt` و`sitemap.xml`.
- صور أسنان وعيادة مرتبطة بالمحتوى باستخدام روابط Unsplash قابلة للاستبدال لاحقًا بصور العيادة الأصلية.

## التقنيات

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Wouter للتنقل بين الصفحات
- Lucide React للأيقونات
- Google Fonts: Cairo وIBM Plex Sans Arabic

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

ثم افتح عنوان Vite المحلي الظاهر في الطرفية.

## فحص TypeScript وبناء Production

```bash
pnpm check
pnpm build
```

ينشئ أمر البناء مجلد `dist/` الجاهز لتشغيل نسخة الإنتاج وفق إعدادات المشروع.

## الرفع على الاستضافة

### استضافة Static مثل cPanel / `public_html`

1. شغّل `pnpm build`.
2. ارفع محتويات `dist/public/` إلى `public_html/`.
3. فعّل إعادة توجيه المسارات إلى `index.html` إذا كانت الاستضافة تحتاج ذلك حتى يعمل المسار `/services` عند فتحه مباشرة.
4. اربط الدومين وشهادة SSL.

### استضافة Node

1. ارفع المشروع أو مجلد البناء حسب نظام الاستضافة.
2. شغّل `pnpm install --prod` عند الحاجة.
3. شغّل `pnpm build`.
4. شغّل `pnpm start` واضبط متغير `PORT` إذا لزم.

## إعدادات تحتاج إلى إضافة يدوية لاحقًا

- **العناوين التفصيلية والخرائط:** أضف عنوان Google Maps ورابط الاتجاهات لكل فرع بعد تزويد البيانات الدقيقة.
- **الحجز الحقيقي:** النموذج الحالي يعمل كتجربة واجهة ويعرض تأكيد استلام محليًا. لربطه بالبريد أو WhatsApp أو نظام مواعيد، يجب إضافة Backend أو خدمة Forms مع حماية وValidation وعدم تخزين بيانات المرضى في الواجهة.
- **الصور:** استبدل صور Unsplash بصور العيادة الأصلية بعد الحصول على الحقوق والموافقات.
- **التقييمات:** قسم التقييمات مجهز لإضافة تقييمات حقيقية بموافقة أصحابها، ولا يحتوي على شهادات منسوبة لأشخاص غير موثقين.
- **وسائل التواصل الاجتماعي:** الروابط الحالية placeholders ويمكن استبدالها بالروابط الرسمية.
- **الدومين والتحليلات:** أضف الدومين النهائي وأي معرّفات Analytics من خلال إعدادات الاستضافة.

## ملاحظات طبية ومحتوى

الموقع تعريفي ولا يقدم تشخيصًا أو نصيحة طبية شخصية أو وعودًا بنتائج. يجب مراجعة المحتوى النهائي من إدارة العيادة قبل النشر.
